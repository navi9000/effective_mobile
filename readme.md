# О проекте

Тестовое задание на позицию разработчика node.js. Задача заключается в разработке сервиса по работе с пользователями. Сервис включает регистрацию, авторизацию пользователей, а также ряд действий с имеющимися пользователями.

## Подготовка проекту к запуску

Необходимо создать .env файл на базе приложенного файла .env.example и прописать нужные переменные. DB_HOST, DB_USER, DB_PASS, DB_NAME, DB_PORT - это переменные для подключения базы данных. Я у себя использовал postgresql и в коде проекта я в явном виде указал именно ее. SERVER_PORT - это порт, на котором будет запущен сервер. JWT_SECRET - ключ для проверки токена типа HS256. Можно сгенерировать, например, здесь: https://jwtsecretkeygenerator.com

## Запуск проекта

- pnpm dev - запуск проекта для разработки
- pnpm build - сборка проекта
- pnpm start - запуск готовой сборки

## Особенности проекта

- Проект на express
- Предполагает подключение postgresql
- Запросы к бд осуществляются через ORM sequelize
- Авторизация пользователей осуществляется через JWT токен
- Обработка токенов вынесена в middleware
